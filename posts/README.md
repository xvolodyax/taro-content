# Пакеты постов

Новый канон: папка на слот, не один файл на всё.

```text
posts/YYYY-MM-DD-HHMM/
```

Пример: `posts/2026-08-27-1212/`. Как собирать — [`POSTS.md`](../POSTS.md).
Шаблоны: [`templates/`](templates/).

## Что здесь нельзя

- Не переписывать уже лежащие пакеты (`2026-08-24-1212` и дальше), однофайловые `posts/*.md` и `polls/` с других веток.
- Не класть рилсы и Remotion в `posts/`. Это `video/`.
- Не писать сегодняшний эфир «чтобы проверить формат».

Старые однофайловые посты (`YYYY-MM-DD-1212.md`) и `polls/` — архив. Новые слоты только папкой.
