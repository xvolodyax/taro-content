# Как хранятся посты

Один файл — один пост. Файлы лежат в `posts/`.

## Имя файла

```
YYYY-MM-DD-slot.md
```

`slot` — время выхода поста: `1212`, `1515`, `1818`, `2121`.

Пример: `posts/2026-08-17-1818.md`.

## Фронтматтер

Каждый файл начинается с блока YAML:

```yaml
---
date: 2026-08-17
slot: 1818
mechanic: три карты
wordstat_query: таро на сегодня
status: draft
---
```

| Поле | Значение |
| --- | --- |
| `date` | Дата выхода, `YYYY-MM-DD` |
| `slot` | `1212`, `1515`, `1818` или `2121` |
| `mechanic` | Название механики дня из `ACTIVITIES.md` |
| `wordstat_query` | Ключевой запрос Вордстата, под который написан пост |
| `status` | `draft`, `review` или `published` |

Ниже фронтматтера — текст поста.

## Планы на день

Планы механик хранятся отдельно: `posts/plans/YYYY-MM-DD.md`.
Как их придумывать — см. [`ACTIVITIES.md`](ACTIVITIES.md).
