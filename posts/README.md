# Пакеты постов

Новый канон: папка на слот, не один файл на всё.

```text
posts/YYYY-MM-DD-HHMM/
posts/YYYY-MM-DD-alena/
```

Пример: `posts/2026-08-27-1212/`, `posts/2026-08-28-alena/`. Как собирать — [`POSTS.md`](../POSTS.md). Алёна: [`ALENA.md`](ALENA.md).
Шаблоны: [`templates/`](templates/), Алёна: [`templates/alena/`](templates/alena/).

## Что здесь нельзя

- Не переписывать уже лежащие пакеты (`2026-08-24-1212` и дальше), однофайловые `posts/*.md` и `polls/` с других веток.
- Не класть рилсы и Remotion в `posts/`. Это `video/`.
- Не писать слот, которого Холл не назвал. Рилсы не сюда.
- Не переписывать уже вышедший день Алёны. Обложку Алёны не класть в `posts/`.

Старые однофайловые посты (`YYYY-MM-DD-1212.md`) и `polls/` — архив. Новые слоты только папкой.
