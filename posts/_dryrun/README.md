# Dry-run роя

Записи шагов без живых пикселей Kie.

```text
python3 scripts/posts_swarm_dryrun.py
```

Проверяет:

1. В репо есть researcher / meaning / copywriter / cover-text / gate. Главреда нет.
2. Gate режет inline Director writing.
3. Gate режет Главред как обязательный шаг.
4. Cloud fallback = `Task(generalPurpose)`.
5. PNG не требуется для записи шага.

Это не слот эфира. Живой пакет: `posts/YYYY-MM-DD-HHMM/`.
