# Агенты — ТАРО СЕЙЧАС

Язык: русский.

## Две машины

1. **Статьи Дзена** — канон [`articles/ARTICLE.md`](articles/ARTICLE.md). Цепочка ниже.
2. **Посты каналов** (Telegram / ВК / Макс, слоты 12:12 / 15:15 / 18:18 / 21:21) — **не эта машина**. Не открывать `posts/`, не писать посты, не менять планы дня.

Если задача про пост, сториз или рилс — остановись. Этот репозиторий держит статьи Дзена в `articles/`.

## Канон статьи Дзена

```text
Тема (Вордстат + портрет)
→ research-brief
→ title-brief
→ Writer (смысл)
→ Главред / Sol (слог, Opus)
→ карточка Дзена (description)
→ обложка: лицо по рефу + cover_hook 2–6 слов на кадре
→ файл обложки 1K
→ публикация Холлом в Студии Дзена
```

Без брифа текст не писать. В эфир только после явной отмашки «можно публиковать».

Прозу после Главреда не переписывать (кроме возврата Главреду при FAIL слога). Description и `cover_hook` — отдельные тексты, не обрезка заголовка и не обрезка лида. Обложка: приём Хорошева (лицо + короткий хук), не его худи/стикеры/quad.

Никто не читает уже вышедшие статьи как образец слога. Для антидубля — только [`articles/published-titles.md`](articles/published-titles.md).

Ошибки пайплайна — в [`articles/pipeline-errors.md`](articles/pipeline-errors.md), скилл `.cursor/skills/dzen-errors`.

## Что сознательно нет

Нет плагина Excalibur, нет WordPress / SFTP / RSS-сайта, нет Gemini-политики моделей, нет quad-split коллажа, нет клона Horosheff/EXCALIBUR. Публикация — Холл в браузере Дзена, канал `todaytaro_bot`, формат **Статья**.
