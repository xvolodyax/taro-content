# Пайплайн статьи Дзена

Единственный канон. Агенты и скиллы только ссылаются сюда, второй канон не плодим.

Чеклист одной статьи:

```text
бриф → title → смысл → Главред → карточка Дзена → хук обложки → файл обложки 1K → публикация Холлом
```

Посты Telegram / ВК / Макс (12:12 / 15:15 / 18:18 / 21:21) — **не эта машина**. Их не открывать, не править, не «дотягивать» под статью.

Ориентир логики — Excalibur-2-Cloud (цепочка Research → Title → Writer → Sol → Description → Cover-text → Cover → Publish, бриф до текста, description ≠ title ≠ лид, ledger заголовков, журнал инцидентов). Сюда перенесена **логика**, не плагин и не репа.

## 1. Тема

Не выдумывать. Не брать «потому что красиво».

Тема = **живой спрос Яндекс Вордстата** + **портрет клиентки** из [`brand-brief.md`](brand-brief.md).

1. Открыть Вордстат (MCP, если есть; иначе живой wordstat.yandex.ru). Записать фразу, число показов, период и дату снятия.
2. Сверить с [`published-titles.md`](published-titles.md). Близкий заголовок или та же боль — тема сгорела.
3. Не брать как новую тему, если уже жёвано:
   - «он не пишет» / «почему он молчит» / «что делать если он не пишет»
   - «дата рождения»
4. Тема должна попадать в портрет: женщины 20–50, ~78% отношения, крючок «Пауза или конец?». Не 13–17, не СВО, не медицина.

Цифры Вордстата не выдумывать. Нет доступа — стоп, не «примерно 12 тысяч».

## 2. Research-brief — до текста

Шаблон: [`templates/research-brief.md`](templates/research-brief.md).  
Папка статьи: `articles/dzen/YYYY-MM-DD-slug/research-brief.md`.

Поля в духе Excalibur. Все обязательны:

| Поле | Зачем |
| --- | --- |
| `reader_pain` | конкретная боль, не абстракция |
| `reader_story` | сцена: кто, что в руках, сколько времени прошло |
| `reader_outcome` | что человек **сделает сегодня** |
| `success_criteria` | как она поймёт, что вопрос закрыт |
| `voice_angle` | человеческий угол, не SEO-формула |
| `surprising_fact` | неожиданный факт или конфликт из источников, с URL и датой |
| `pain_solution_map` | боль → H2 (живой вопрос) |
| `wordstat` | фраза, показы, период, дата снятия |

Без брифа Writer **не пишет**. Дырявый бриф — вернуть в Research, не «додумать в тексте».

Не читать старые статьи сайта и не читать `article.md` прошлых папок как образец слога. Ledger — только заголовки и запросы.

---

## 3. Title отдельно от карточки и от хука обложки

Шаблон: [`templates/title-brief.md`](templates/title-brief.md).

- Заголовок содержит запрос Вордстата (или ближайшую естественную форму).
- Это не description карточки и не надпись на обложке. Три разных текста.
- Понятная тема, не ярлык, не «Тишина в чате: хроника одного вечера».
- Сверить с ledger: не каннибалить уже вышедший H1.

Так: «Что делать, если он не пишет».  
Так нельзя: поэтический H1 без запроса; H1 = будущий description; H1 = `cover_hook` слово в слово.

---

## 4. Writer = смысл

Файл: `writer.md` в папке статьи. Факты, структура, вопросы к картам. Слог не наводить — это зона Главреда.

Раньше смысл писал Sonnet. Для постов человек перешёл на Opus. Для статей Дзена смысл **остаётся отдельным шагом**; слог правит Главред-Opus.

### Старт

Со сцены / боли из `reader_story` / `reader_pain`. В первых абзацах — прямой ответ на запрос Вордстата (SEO/GEO: текст должен цитироваться как ответ в Google AI и Яндекс Нейро). Сцена и ответ — один лид, не учебник и не «разгон».

Не открывать:

- «что такое таро»
- «в этой статье»
- «в современном мире»
- «мы рассмотрим»

### Структура

- H2 — живые вопросы из `pain_solution_map` («Писать первой или ждать», не «Тонкая грань»).
- Каждый H2 закрывает одну боль и даёт действие / чего не делать.
- Вопросы к картам — конкретные, после которых понятно, что делать сегодня. Не «любит или нет», не «что он думает».
- Язык: простой «ты», женский род, конкретная сцена. Длинное тире (—) не ставить: точка, двоеточие, запятая.

### Стоп-лист смысла

- таргет 13–17, СВО, медицина
- пугать одиночеством («останешься одна»)
- обещать прочитать мысли / «что он чувствует»
- ссылки на Telegram
- хештеги
- сырые URL в теле (воронка — гиперссылки в слова, шаг 9)

Writer не читает старые статьи как слог. Источник правды: бриф + title-brief + brand-brief.

---

## 5. Главред / Sol = единственный стилевой проход

Файл: `article.md`. Вход: `writer.md` + бриф + title. Модель слога: **Opus**.

- Переписывает слог. Не выдумывает факты, которых нет в черновике и брифе.
- Не добавляет новых карт, цифр Вордстата, чужих историй, ссылок.
- Не открывает учебником, если Writer уже открыл сценой.
- После Главреда прозу больше никто не «улучшает». FAIL слога → снова Главред, не третий автор.

В эфир — **только** после явной отмашки человека: «можно публиковать». Пока отмашки нет, статус `review`.

---

## 6. Description = тизер карточки Дзена

Шаблон: [`templates/dzen-description.md`](templates/dzen-description.md).

Это текст карточки в ленте Дзена. **Не равен title. Не обрезка лида.** Иначе в ленте две одинаковые карточки (урок Excalibur: description = лид → двойной текст; description = title → заголовок дважды).

| Правило | Значение |
| --- | --- |
| Длина | 80–180 символов, цель ~120 |
| Объём | одно предложение, редко два коротких |
| HTML / эмодзи / URL | запрещены |
| Повтор title | запрещён (exact и «почти exact») |
| Повтор opening | запрещён (не префикс / не обрезка первого абзаца) |
| Кликбейт / ALL CAPS / мат | запрещены |

Проверка вслух: title и description подряд — два разных текста? Первый абзац `article.md` — не его укороченная копия?

## 7. Обложка: приём Хорошева, не его стиль

Шаблон: [`templates/cover-brief.md`](templates/cover-brief.md).

Берём **приём** (лицо бренда + короткий текст смысла на кадре). Не берём **design code** Excalibur.

На обложке обязательно два слоя:

1. **Лицо бренда** — image-to-image по референсу, не выдуманный двойник.
2. **Короткий текст смысла / cover-hook** — 2–6 слов на самом кадре. Пустая атмосфера без надписи не сдаём.

`cover_hook` ≠ title статьи ≠ карточка Дзена. Три разных текста. Заголовок на обложку не копировать.

### Лицо

| Правило | Значение |
| --- | --- |
| Рефы | `images/refs/` — Виктория и Алёна, лицо + поясной портрет |
| По умолчанию | **Виктория** |
| Алёна | только если статья про неё или явно её слот |
| Нет рефа | `face: none`, кадр без человека. Похожее лицо «по памяти» нельзя |

Модель:

- есть реф → **Kie.ai `gpt-image-2-image-to-image`**
- рефа нет → `gpt-image-2-text-to-image`, человека нет
- разрешение **1K, не 2K**

### Кадр

Светлый современный: окно, лён, стекло, дневной свет. `scene_hint` в брифе — конкретная бытовая сцена статьи, не «мистика».

Запрет кадра: тёмный стол, свечи, готика, «магический подвал».

Запрет стиля Excalibur (`forbidden_style` в брифе, не вычёркивать): белое худи, мемные стикеры, скотч-коллаж, «лох», quad 2×2 canvas, 2K.

Плагин Excalibur не ставить. Если влит `images/PROMPTS.md` — для **статей Дзена** этот §7 главнее: на обложке статьи хук **нужен** (для постов «без букв» может остаться их правило).

### Файл

Файл на диск в папку статьи (`cover.png` / `cover.jpg`). В Дзен грузить **файлом**, никогда `localhost` / `127.0.0.1`.

## 8. Публикация

Делает **Холл** в браузере Студии Дзена.

- Канал: `todaytaro_bot`
- Формат: **Статья**, не пост
- Без хештегов
- Без ссылок на Telegram
- Обложка: файл с диска, не URL локалхоста
- Не WordPress, не SFTP, не RSS-сайт

Известные ямы — [`pipeline-errors.md`](pipeline-errors.md): `localhost` в обложке, `/new-publication` → 404. Не повторять.

После выхода: дописать строку в [`published-titles.md`](published-titles.md). Без этого следующая тема может каннибалить эту.

## SEO / GEO (статьи)

GEO здесь — Generative Engine Optimization, не география. Текст должен удобно цитироваться как ответ (Google AI Overviews / AI Mode, Яндекс Нейро / Алиса).

1. Запрос Вордстата — в заголовке.
2. Первые абзацы — ответ + сцена, без «в этой статье».
3. H2 — настоящие вопросы.
4. Один вывод на раздел, шаги лучше тумана.
5. Ключ не натыкивать в каждый абзац.

Если влит `texts/SEO-GEO.md` — читать его тоже. При конфликте со слотом постов: для **статей** действует этот файл; правило «первая строка поста — сцена, не запрос» остаётся у постов.

## Статусы файла `article.md`

Фронтматтер:

```yaml
---
title: "…"
slot: "09:00"          # или 16:00 / 20:00
wordstat_query: "…"
wordstat_period: "…"
wordstat_accessed: 2026-08-21
funnel: max            # max | vk
status: draft          # draft | review | approved | published
cover_file: cover.png
---
```

`approved` — только после «можно публиковать».  
`published` — только после реальной выкладки Холлом + строки в ledger.
