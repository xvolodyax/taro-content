# Title-brief

Скопировать в `articles/dzen/YYYY-MM-DD-slug/title-brief.md`.  
Это только H1. Не карточка Дзена и не хук обложки.

```text
topic_id: DZEN-YYYYMMDD-слот
wordstat_query:
h1:
title:          # обычно = h1
subject:        # о ком / о чём статья одной фразой
angle:          # чем этот H1 не повтор ledger
verdict: PASS | FAIL
```

## Проверка

- [ ] в H1 есть запрос Вордстата или ближайшая естественная форма
- [ ] H1 ≠ будущий description
- [ ] H1 ≠ будущий `cover_hook` (2–6 слов на кадре)
- [ ] нет в `published-titles.md` (exact и соседняя боль)
- [ ] не ярлык, не поэзия без запроса, не «Что такое … и как»
- [ ] прочитан вслух: понятно, о чём материал
