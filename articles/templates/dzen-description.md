# Карточка Дзена (description)

Скопировать в `articles/dzen/YYYY-MM-DD-slug/dzen-description.md`.  
Писать **после** Главреда, по финальному `article.md`. Прозу статьи не трогать.

```text
topic_id: DZEN-YYYYMMDD-слот
title:                 # тот же H1, для сверки, не для копирования
description:
char_count:
verdict: PASS | FAIL
```

## Правила

- 80–180 символов с пробелами, цель ~120
- одно предложение (редко два коротких)
- plain text: без HTML, эмодзи, URL, хештегов
- ≠ title (exact и «почти exact»)
- ≠ обрезка первого абзаца `article.md`
- честно: о чём материал и зачем читать
- без кликбейта, ALL CAPS, мата

## Self-check

1. Title и description подряд вслух — два разных текста?
2. Первый абзац статьи — не укороченная копия description?
3. Новичок поймёт без эзотерического словаря?
4. Длина 80–180?

FAIL любого пункта → новая попытка, не stamp и не публикация.
