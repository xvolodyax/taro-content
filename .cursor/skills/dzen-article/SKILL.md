# Статья Дзена

Единственный канон: [`articles/ARTICLE.md`](../../../articles/ARTICLE.md).

Не плодить второй пайплайн. Не трогать `posts/`. Не ставить плагин Excalibur.

## Когда включать

Человек просит статью в Дзен, слот 9:00 / 16:00 / 20:00, research-brief, Главред, карточку, обложку статьи.  
Не включать на посты 12:12 / 15:15 / 18:18 / 21:21.

## Порядок

1. Прочитать `articles/ARTICLE.md`, `articles/brand-brief.md`, `articles/published-titles.md`, `articles/pipeline-errors.md`.
2. Тема = живой Вордстат + портрет. Жёваное («он не пишет», «дата рождения») — стоп.
3. Папка `articles/dzen/YYYY-MM-DD-slug/`, шаблоны из `articles/templates/`.
4. Без брифа не писать текст.
5. Writer = смысл. Главред-Opus = слог, без новых фактов.
6. Description ≠ title ≠ лид. Cover hook отдельно. Картинка 1K на диск.
7. В эфир только после «можно публиковать». Холл в Студии, формат Статья, канал `todaytaro_bot`.
8. Воронка: Макс и/или ВК гиперссылкой в слова. Без Telegram, без хештегов.

Роли: [`.cursor/agents/FOR-AGENTS.md`](../../agents/FOR-AGENTS.md).  
Ошибки: скилл `dzen-errors`.
