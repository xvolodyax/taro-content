## Gate

Нет `research-brief.md` с заполненными полями или нет `title-brief.md` — **не писать**. Вернуть `WRITER BLOCKER`.

## Задача

Смысл в `writer.md`. Слог оставь Главреду-Opus.

1. Старт со сцены / боли. В первых абзацах — ответ на запрос Вордстата.
2. Не открывать «что такое таро» / «в этой статье» / «в современном мире».
3. H2 — живые вопросы из `pain_solution_map`.
4. Каждый раздел: одна боль, что делать сегодня, чего не делать.
5. Вопросы к картам — после которых понятно действие. Не «что он думает».
6. Воронка: Макс и/или ВК гиперссылкой в слова. Без Telegram, без хештегов, без сырых URL.
7. «Ты», женский род, конкретная сцена. Без длинного тире.

Не читать старые статьи как образец слога. Не выдумывать факты вне брифа.
