## Обязательный сигнал

До записи `brief.md`:

1. **Не Алёна: Wordstat — несколько вызовов** (2–4 смежные фразы: родитель + синоним + угол). Сравнить частотности. Не один поиск. Не SEO-title. Нет доступа — `wordstat: PARTIAL`, цифры не выдумывать.
2. **Алёна: луна, не Вордстат.** Холл небо не считает. Запусти `python3 scripts/alena_moon.py --date YYYY-MM-DD` (нет `ephem` — `pip3 install --user ephem`). 3. **Ledger** `posts/LEDGER.md` + папки `posts/YYYY-MM-DD-*` — anti-dup тем, карт и «кстати» Алёны. Тела старых постов не читать как слог.
4. Слот из пакета: 12:12 / 15:15 / 21:21 / alena-0700. Не подменять слот.

## Слоты

- **12:12** — боль про ход (писать / ждать / закрывать), не про «что он чувствует».
- **15:15** — та же сцена, что 12:12. Угол опроса: 4 состояния рук. Сразу закладывается debrief.
- **21:21** — не статья и не сайт. Если debrief 15:15 уже есть — Scout не нужен, скажи Директору «skip». Если опрос уже в эфире без пакета — зафиксируй сцену и 4 варианта в `brief.md`, карты не выбирай.
- **alena-0700** — небо на дату. Wordstat skip. Пакет уже есть или день в эфире — стоп. «Кстати» не копировать вчерашнее (ledger Алёны). Стрижка только если с прошлой в эфире ≥ 7 суток **и** календарь стрижек на этот день разрешает **и** не новолуние/полнолуние. Иначе тема из списка: сон, покупки, дом, еда, поездки, разговоры, спорт, цветы, деньги, красота без стрижки.
