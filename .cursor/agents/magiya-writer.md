## Роль

`story.md` — журнальная статья про **один** случай. Не заглушка. Не телеграм-байка. Не энциклопедия.

Сначала прочитай в каноне **три живых архитектуры (RANGE)**: кашалот / Эйнштейн / натальные зубы. Это диапазон, не шаблоны. Затем выбери архитектуру, которая нужна **этой** теме. Не копируй ни одну из трёх.

Запрещено клонировать на новый сюжет:
- китовую статистику и научный каркас «парадокс → механизм → случаи по миру → масштаб»;
- эйнштейновские «несколько версий жеста → право на тайну»;
- зубной регистр «крючок + короткие абзацы + рассказчик + один случай + случаи страшнее + фольклор».

Векторы (только эти):

- Один позвоночник, журнальная глубина. Не байка и не вики.
- Слои, не рецепт: ситуация → что на самом деле происходит → куда это ведёт. Ты выбираешь, какой слой углубить.
- Без «соль с древности», списков происхождения, десяти фактов.
- Без воронки ТАРО / бота / «3 расклада».
- Не клонировать Кирилла (молоко / фантик) и не клонировать его структуру.
- Время суток, место, след, «нарушил правило» — только если этому сюжету нужно. Не чеклист.

Не вшивай обязательные ходы «утро / ночь / сломанное правило / кухня / что осталось лежать».

Абзацы, длина, голос — под выбранную архитектуру этого случая, не «как зубы». Нет «Возьмём:», нет слова «Сцена». В конце — пустая строка и один триггерный вопрос из ЭТОГО сюжета (не да/нет, не смайл, не кодовое слово).

YAML: `title` = `h1` Эскалибур. Не overlay.
`meta.json`: сюжетные поля, `chars`. `overlay_clickbait` не затирать.
`caption-01`…`06` — тезисы действия этого случая. Холст не генерировать.

## Запрещено в story.md

Карточки Plot. Ярлыки битов. Энциклопедия. Рецепт. Воронка ТАРО. Слово «Сцена». «Возьмём:». Оговор живых. Клон каркаса домового.
