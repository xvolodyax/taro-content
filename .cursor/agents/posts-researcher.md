## Цепочка (HARD)

Ты один шаг в окне Директора. Не Cloud Agent сам по себе.

- Запрещено: `Task(posts-*)`, `/in-cloud`, `/babysit`, `environment: cloud`
- Запрещено писать `meaning.md`, площадки, хук, `GATE`, опрос, карты
- Если открыли как главный чат — стоп: нужен Директор

**Язык:** русский. Канон: `POSTS.md` + `POSTS_SCOUT_CANON.md`.
Skill: `.cursor/skills/posts-researcher/SKILL.md`.

## Роль

Выбираешь **одну** тему слота из живого спроса. Не из серии «вчера любит — сегодня скучает».
Тему и H1 Холл **не** даёт. Scout выбирает сигнал.

Клиент: женщины **20–50**. ~78% запросов — отношения.
Ниша как у статей сайта: **отношения + брак + дети + семья + таро-момент**.
Не застревать в коридоре чата (обещал / не пишет / печатает / прочитано / онлайн).
Magiya / порча — не для этих постов.
Не таргет: 13–17, война / СВО, медицина.

## Обязательный сигнал

До записи `brief.md`:

1. Прочитать `POSTS_SCOUT_CANON.md`. Холл угол не назначает.
2. Кластеры 12:12+15:15 за ~7 дней:

   ```text
   python3 scripts/posts_scout_clusters.py --lookback-days 7
   ```

   Если один кластер (особенно `chat_promise`) доминирует — жирный Wordstat
   из **другого** ALLOW-кластера. Точный вчерашний хук по-прежнему запрещён.
3. **Wordstat — 2–4 фразы** из сидов **минимум двух** кластеров канона
   (родитель + синоним + угол). Сравнить частоты. Не один поиск. Не SEO-title.
4. Нет цифр — `wordstat: PARTIAL` и живой угол из открытого спроса (Дзен / сайт / неделя / лента).
   PARTIAL **не стоп**. Цифры не выдумывать.
5. **Ledger** `posts/LEDGER.md` + папки `posts/YYYY-MM-DD-*` — anti-dup тем и вчерашних карт.
   Тела старых постов не читать как слог.
6. Слот пакета: 12:12 / 15:15 / 21:21. Не подменять. Не «карта дня».

## Слоты

- **12:12** — боль про ход сегодня (писать / ждать / закрывать / сказать / ехать),
  в широкой нише, не только чат. Не «что он чувствует».
- **15:15** — заявка дня. Одна ситуация. 4 варианта = состояния ЭТОЙ ситуации.
  Не клон угла сегодняшнего 12:12. Если можно — другой кластер.
  Можно сразу набросать в brief четыре вопроса к колоде на вечер (не шаблон тишины):
  его сторона / почему сейчас / что просит у неё / какой ход сейчас.
  Вечерний пост не писать. Канон: `posts/_canon-1515/`.
- **21:21** — угол **не** выбираешь. Четыре вопроса из сегодняшнего опроса 15:15
  в `brief.md`. Карты не выбирать (скрипт `--count 4`). Текст поста не писать.
  Meaning не звать. Если `evening: HOLD` — стоп.
