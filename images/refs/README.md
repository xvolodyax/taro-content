# Референсы для режима i2i

## Логотип бренда (в репозитории)

`taro-seichas-logo.png` — круглый золотой медальон «ТАРО / СЕЙЧАС».
Его **коммитим**. На каждом кадре к посту медальон вшивается в генерацию
(`gpt-image-2-image-to-image`), не клеится сверху. Правила — `images/PROMPTS.md`, пункт 8.

## Лица (не в репозитории)

Сюда нужно положить приватные фотографии — они используются только как референс лица для `gpt-image-2-image-to-image`. В PR и в публичные материалы фотографии не попадают (см. `.gitignore`).

Что положить: 2–4 файла на человека с такими именами:

- `victoria-1.jpg`
- `victoria-2.jpg`
- `alena-1.jpg`
- `alena-2.jpg`

Требования к фото:

- одно — лицо крупно (анфас, лицо не перекрыто), одно — по пояс;
- хороший ровный свет, лицо не в тени;
- без тёмных очков, без сильных фильтров, без чужих лиц в кадре;
- достаточное разрешение (по возможности от 1024 px по короткой стороне).

Пока файла нет, лицо этого человека не генерируем: агент пишет об этом в выдаче и делает кадр без человека (см. `images/PROMPTS.md`, пункт 7).
