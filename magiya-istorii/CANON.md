# Канон «Магия истории»

Отдельный продукт. Не посты «ТАРО СЕЙЧАС». Не Алёна. Не 12:12 / 15:15 / 21:21.
Не канал боли. Не продажа раскладов. Не бот и не приложение.

Тема **всегда магия**: обряд, чёрная магия, духи, колода, проклятие, сглаз, вызов.
Город и год — только если через них идёт обряд. Чистая бытовая повесть без эзотерики = брак.

## Форма

- Первый абзац уже сцена. Не лекция, не определение, не «в этой истории». Слова «Сцена» нет.
- Одна ночь / один человек / один обряд. Не сага, не три поколения, не обзор традиции.
- Имена, город, дата, бытовая фактура: чай, автобус, запах сырой варежки, номер квартиры.
- Напряжение до последней строки: крючок → ставка → поворот → затяжка → цена.
- Обряд виден в сцене у персонажа. Это не рецепт читателю. Нет «сделай так, чтобы испортить».
- Выдумка или документ — только в `meta`. В рот читателю не класть «это вымысел» / «реальная история».
- Живых людей не оговаривать. Знаменитость, сосед, клиент — не герой «документа», если он жив.

## Длина

Повесть: **8 000–14 000** знаков с пробелами в `story.md` (тело, без YAML).
Хочется дочитать. Воздух ради воздуха — резать.

## Язык

Русский. Настоящее или близкое прошедшее. Конкретный глагол.
Длинное тире не запрещено (это не посты каналов), но не им держать ритм.
Не SEO-глажка. Жирная фраза Вордстата **не** обязана быть H1.

## Стоп

- Рецепт обряда, дозировки, «как навести / снять»
- Продажа расклада, ссылка на бота / приложение «ТАРО СЕЙЧАС», воронка 12:12
- Боль «он не пишет / не написал / молчит в чате» как тема
- Лекция «что такое магия», энциклопедия, список видов порчи
- Слово «Сцена» как маркер абзаца
- Оговор живого человека
- Вика / Виктория как лицо кадра, логотип «ТАРО СЕЙЧАС» на картине
- Публикация в соцсети из этого продукта

## Картина

Один кадр: кинокадр или живопись. Предмет + свет + цена ночи.
Не коллаж. Не лого. Пиксели рисует Холл, если попросит. В обычном прогоне достаточно `art-brief.md`.
