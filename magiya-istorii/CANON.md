# Канон «Магия истории»

Отдельный продукт. Не посты «ТАРО СЕЙЧАС». Не Алёна. Не 12:12 / 15:15 / 21:21.
Не канал боли. Не продажа раскладов. Не бот и не приложение.

Тема **всегда магия**: обряд, чёрная магия, духи, колода, проклятие, сглаз, вызов.
Город и год — только если через них идёт обряд. Чистая бытовая повесть без эзотерики = брак.

## Форма и подача (уникальная драматургия, слог эталона)

В рот читателю идёт только `story.md`. `plot.md` — служебный. Карточки «Кто / Где / Ставка / Поворот / Цена» и ярлыки битов в прозу не тащить.

Эталон (натальные зубы) задаёт **ритм и слог**, но **НЕ сюжетный шаблон-каталог** и **НЕ телеграм-байку** в три абзаца:
- Короткие абзацы (1–3 предложения), пустая строка между ними.
- Простой чистый русский язык без вычурных заумных метафор.
- Крючок в первой строке.
- Вопрос в конце.

Это **журнальная статья** про один случай, не байка в канал и не досье.

### Слой статьи: один случай, четыре хода (HARD, 29.08.2026)

Держать **ОДИН** случай. Развернуть его как feature, не как байку про Кирилла и не как каталог городов.

В прозе должны читаться все четыре слоя (ярлыки «1) 2) 3) 4)» в рот не тащить):

1. **Что человек сделал руками** — конкретное действие этой ночи, не инструкция читателю.
2. **Какое правило обряда он нарушил** — одна живая норма этого обряда (не энциклопедия «соль с древности»).
3. **Что физически осталось к утру** — след, который можно увидеть/потрогать: крупинки, дорожка, пятно, пустое место.
4. **Почему это не совпадение** — одна деталь, из-за которой бытовое объяснение не держит.

«Что-то хуже» = утро и цена **этого** случая, не второй город и не вторая фамилия.

### Запрет шаблонного каталога городов и энциклопедии (HARD):
- **ЗАПРЕЩЕНО клонировать одинаковый каркас сюжета:** `крючок → герой → «в народе называют» → «честно говоря» → приметы → город 2015 → город 2019 → самый жуткий 2022 → возврат → вопрос`.
- **ЗАПРЕЩЕНО начинать три абзаца подряд с «В 20XX году в Городе»** и собирать искусственные списки городов/годов.
- **ЗАПРЕЩЕНО** раздувать статью энциклопедией: «соль с древности», славянские истоки, десять фактов, виды порчи, лекция «что такое магия».
- **ЗАПРЕЩЕНО** короткая байка в духе «поставил блюдце — хрустнуло — утром молоко убыло — вопрос» без слоёв 2–4.
- **Каждая история уникальна по форме и подаче:**
  - одна цельная ночь от завязки до финала;
  - один случай, который разворачивается в одной локации;
  - последствия одного поступка к утру;
  - плотная история без искусственных отвлечений на чужие города.
- **Компактность и плотность:** без лишней воды и растянутых описаний. Резать воздух и повторы, оставляя чистое действие и напряжение.

1. **Первая строка** — крючок-парадокс в одно короткое предложение. Не досье. Слова «Сцена» нет. Нет «Возьмём:».
2. Обряд в действиях персонажа, не инструкция читателю. Нет «сделай так, чтобы испортить».
3. Выдумка или документ — только в `meta`. Живых не оговаривать.
4. Лид один раз в теле. Под H1 лид не дублировать.

## Финал истории (триггерный вопрос)

После последнего абзаца сюжета ставится **пустая строка и ровно ОДИН вопрос**:
- Вопрос строго из **этой конкретной истории** (не универсальный шаблон).
- Вынуждает развёрнутый осмысленный комментарий: выбор плюс «почему» или короткая личная ситуация из жизни. На него невозможно честно ответить «да», «нет», плюсом, смайликом или одним словом.
- Запрещены: кодовые слова, воронка ТАРО, бот, приложение, «напишите слово в комментариях».
- Не лекция и не второй абзац. Одно-два предложения простым языком без заумных метафор.

## Два жёстких правила названия

Два разных текста. Смешивать нельзя.

### 1. H1 и title статьи — канон Эскалибура, не кликбейт

Пишет **Title** (или Writer, если Title ещё не раздали). Как в taro-excalibur / Дзен-Title:

- Scout даёт живой след: родитель / синоним / угол. Цифры из Wordstat, не из головы.
- **Самую жирную фразу Вордстата в H1 не клеить.** Угол уже, естественнее, из results/associations, не топ-1 «проклятие».
- `H1 == title`. Одно поле по смыслу, два ключа в `meta.json` с **одинаковой** строкой.
- Называется как нормальная статья. Не орёт. Понятно вслух, о чём материал.
- Без ярлыка слота, без «карта дня», без слова «Сцена», без продажи расклада, без бота.
- Не поэзия без запроса. Не «Тишина в подъезде: хроника одной ночи» без живого следа.
- **Clickbait к H1 не допускается.** Overlay с кадра 1 сюда не копировать.
- В `title`, `h1`, slug/URL, meta title статьи кликбейта нет.

Так: «Зачем сыплют соль на порог».  
Так нельзя: «СОЛЬ НА ПОРОГЕ — ОН УЖЕ НА ЛЕСТНИЦЕ»; H1 = «проклятие»; H1 = overlay кадра 1.

### 2. Кликбейт только на картинку

Только overlay на **кадре 1** холста + красная окантовка этого кадра.

- Пишет роль **Clickbait**. Один вариант, не список.
- Напряжение, магия, конкретность (имя / город / обряд).
- Без продажи расклада, без «он не написал», без слова «Сцена», не самый жирный Wordstat в лоб.
- В `title` / `h1` / URL / meta title статьи **не попадает**.
- Clickbait **не имеет права** менять `title` / `h1` / `story.md`.
- Art на кадр 1 кладёт **только** текст из `clickbait.txt`. Свой заголовок не придумывает.

Кадры 2–6: без overlay, без красной рамки.
