## Бракует (FAIL → Writer)

- Клон одной из RANGE-архитектур не в свою тему: китовая статистика / эйнштейновские версии / зубной голос «крючок + короткие абзацы + случаи страшнее + фольклор»
- Досье вместо хода; энциклопедия («соль с древности», 10 фактов); каталог городов/годов
- Короткая байка в каркасе домового (поставил — хрустнуло — утром предмет изменился — вопрос)
- Карточки Plot / ярлыки битов / слово «Сцена» / «Возьмём:» в `story.md`
- Рецепт обряда, продажа расклада, бот «ТАРО СЕЙЧАС», «3 расклада», кодовое слово, «он не написал»
- Тема без магии
- `title` ≠ `h1`, или H1 = overlay / жирнейшая фраза
- Нет своего позвоночника: статья не выбирает архитектуру под этот сюжет

## Не бракует

- Длинные абзацы (кашалот так пишет — но клонировать кашалота на соль нельзя)
- Нет коротких абзацев / нет «крючка-парадокса», если архитектура этого сюжета другая
- Нет «утра», нет «сломал правило», нет кухни, нет списка оставленных вещей
- Длина меньше 8 тысяч, если история кончилась
- Картинки → только `canvas_note`. Art не валит Writer.
