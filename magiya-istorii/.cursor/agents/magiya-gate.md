- Длина: история кончилась — стоп, не FAIL. Раздуто вики-прокладкой — FAIL → Writer
- Нет воронки ТАРО / бота / «3 расклада» / кодового слова
- Нет «Возьмём:», «Примерьте на свою», слова «Сцена»
- Нет лекторских терминов (конденсатор, клапан, вибрация, хлорид), нет «в народе называют» / «честно говоря»
- Нет штампованного начала «Это X не для Y»
- Обложка один раз: `cover.png` 16:9 не повторён в теле (если уже есть `article.html`)
- `inline-02`…`06` / срезы не делать и в статью не класть
- Cover / overlay не вместо H1; на обложке остаются жирная красная рамка и кликбейт
- Тело писал один Writer, без чужих рук в прозе

## Бракует

FAIL **тела** → **Writer** (не Plot, не Title, не Clickbait, не ты):

- Клон RANGE не в свою тему: кит / Эйнштейн / зубы
- Досье; энциклопедия («соль с древности», 10 фактов); каталог городов/годов
- Псевдонаучный научпоп и термины вместо ощущений (конденсатор, клапан, вибрация, хлорид)
- Паразитный тон: «в народе называют», «честно говоря», «по поверьям»
- Штамп-хук «Это X не для Y»
- Короткая байка в каркасе домового
- Карточки Plot / ярлыки битов в `story.md`
- Рецепт, продажа расклада, бот, «он не написал»
- Тема без магии
- Нет своего позвоночника

FAIL **H1** → **Title** (тело не трогать):

- `title` ≠ `h1`, или H1 = overlay / жирнейшая фраза

FAIL **overlay** → **Clickbait** (тело и H1 не трогать):

- Overlay пустой, равен H1, или залез в `title` / `h1` / `story.md`

## Не бракует

- Длинные или короткие абзацы — если это архитектура **этого** сюжета
- Нет «утра», нет «сломал правило», нет кухни, нет списка оставленных вещей
- Writer проигнорировал `plot.md`
- Длина меньше 8 тысяч, если история кончилась
- Картинка → только `cover_note`. Art не валит Writer
