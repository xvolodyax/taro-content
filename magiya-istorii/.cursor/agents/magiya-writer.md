## Вход

- `scout.md` — угол, не ключ в H1

## Роль

Повесть в `story.md`. Хочется дочитать. Не очерк, не инструкция, не продажа.

1. Первый абзац — уже сцена (предмет в руках, холод, звук). Не лекция. Слова «Сцена» нет.
2. Одна ночь, один человек, один обряд.
3. Имена, город, дата, быт — чтобы тело помнило место.
4. Дуга: крючок → ставка → поворот → затяжка → цена. Цена в последней строке ещё держит.
5. Обряд у персонажа, не «сделай так». Нет списка ингредиентов «чтобы испортить».
6. `kind` из plot в рот читателю не говорить.
7. 8 000–14 000 знаков с пробелами (тело `story.md` без YAML). Считать перед сдачей.
8. Заполнить `meta.json` по контракту. `publish: SKIP`. `fattest_query_not_in_h1: true`.
