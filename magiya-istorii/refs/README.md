## Анти-морф (HARD)
1. **12 клеток на листе = одна и та же Вика** с разных углов, а не 12 разных людей.
2. **ЗАПРЕЩЕНО усреднять / морфить / блендить 12 лиц** в абстрактную «среднюю внешность».
3. Для идентичности лица модель должна опираться на **ОДИН ракурс с листа** (анфас или 3/4). Остальные клетки служат исключительно подсказкой угла поворота головы, а не вторым персонажем.
4. Позы, одежду и свет с реф-сетки **не копировать**. Наряд и свет — из сюжета этой истории, не «ночь» из базового промпта.
5. **CHARACTER LOCK (16.09, как у статей):** age **33**, youthful early-thirties (не 40+/45/50, не mature/aging); тёплый honey/wheat блонд с более тёмными корнями; глаза зелёные с лёгким карим; кожа photoreal (поры, без plastic/airbrush); лицо крупное и читаемое. Слабый lock «Victoria age 33» без волос/глаз/кожи — брак.
6. Лицо с рефа — **только клетка cover** холста 2K 16:9 2×2: сначала lock, потом микрофон в руке, жирная красная рамка + кликбейт. Рамка/mic/пропсы лицо не сжимают. Врезки `inline-01`…`03` без лица Вики. Реф-лист из 12 ракурсов — только исходник лица, не сетка статьи. Negative: age 40+, mature, aging, brown/grey eyes, plastic skin, face morph, tiny face, text on face.
7. Если файла рефа нет на диске VM — в брифе ставится `face: pending-ref`, пиксели не стартовать, лицо по памяти не выдумывать.
8. Не Алёна. Не лого «ТАРО СЕЙЧАС». Холл лицо руками не рисует.
